# Get help

Use the repository's Issues tab for questions, bug reports, and feature requests.
Use a pull request to propose a change.
Updates follow the maintainer's needs. There is no response or release schedule.
See [CONTRIBUTING.md](CONTRIBUTING.md) before you prepare a change.

## Report a problem

Include the MousePilot version and the operating system version.
Include the MCP client name and the monitor layout when these affect the problem.
State the action, the expected result, and the actual result.
Use test data to show the problem.
Remove tokens, private paths, private window titles, and private images.

Start with [configuration](docs/configuration.md) for connection problems.
Use [targeting](docs/targeting.md) for coordinate and focus problems.
Use [llama.cpp setup](docs/llama-cpp.md) for missing screenshot images in that client.
Use [testing](docs/testing.md) for the live test tools.

## Report private information

Follow [SECURITY.md](SECURITY.md) for a security report.
Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for a conduct report.
Do not put private report details in an issue or PR.
