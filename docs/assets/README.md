# Desktop demo assets

Use these files for the demos in the project README.
The demos show MousePilot desktop control on
[QA Practice Hub](https://qapracticehub.com/).

## Files

| Platform | README animation | Full video | Preview image |
| --- | --- | --- | --- |
| macOS | `macos-demo.gif` | `macos-demo.mp4` | `macos-demo-poster.png` |
| Windows | `windows-demo.gif` | `windows-demo.mp4` | `windows-demo-poster.png` |

The GIF files show selected actions and loop automatically.
The MP4 files show longer demos with captions.
The PNG files provide still images for video previews.

## Demo content

The macOS demo uses Safari Private Browsing.
The Windows demo uses Microsoft Edge InPrivate.
Both show screenshot-based clicks, text entry, keyboard shortcuts,
scrolling, dragging, and button interactions through MousePilot over SSH.
The demos use native desktop input without browser DOM automation.

The videos have no audio. Setup and pauses are trimmed.
The demos use test form data, including `MousePilot` and `demo@example.com`.

## Replace a demo

Keep the file names above when you replace a demo.
Use test data and exclude credentials, personal tabs, and desktop files.
Check the video and animation before you add them to the repository.
Keep raw recordings and temporary scripts outside the published assets.
Update the README links if the file names change.
