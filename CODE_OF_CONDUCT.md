# Code of conduct

Treat contributors and users with respect. Technical disagreement is welcome;
personal attacks, harassment, discrimination, threats, doxxing, and sharing
someone else's private information are not.

Keep reports and reviews relevant and constructive. Explain technical concerns
with evidence, give people room to correct mistakes, and respect boundaries.
Do not include other people's desktop captures or credentials without consent.

Maintainers may edit or remove disruptive content and restrict participation.
Actions should be proportionate to the behavior and its impact. Maintainers are
held to the same standards as other participants.

For a private conduct report, request a private contact channel through the
repository owner's GitHub profile. If none is available, open a minimal issue
asking for private contact without naming affected people or describing private
incidents publicly. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
